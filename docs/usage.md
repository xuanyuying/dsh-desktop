# 使用手册

## 安装与启动

1. 从 [Releases](https://github.com/xuanyuying/dsh-desktop/releases) 下载 `DSH Desktop Setup x.y.z.exe`
2. 双击安装（可选择安装目录；无需管理员权限）
3. 首次启动会自动完成：定位 `dsh` → 未安装则 `npm install -g @deepseek-ai/dsh` → 启动 `dsh web` → 加载界面

> 前置条件：已安装 **Node.js 18+**。应用会自行安装 `dsh`，但不会替你安装 Node.js。

## 两处常驻显示

应用把「峰谷时段 + 账户余额」放在菜单栏里，而不是页面浮层上——**原生菜单不会遮挡页面内容，也不会抢走点击**。

菜单栏最右侧（紧接「帮助」之后）的标签形如：

```
空闲，2小时30分转高峰，余额：¥7.33
高峰，1小时30分转空闲，余额：¥7.33
```

点击它会展开：

| 行 | 含义 |
| --- | --- |
| 时段 · 折扣 | 当前是高峰（标准价）还是空闲（5 折） |
| 倒计时 | 距离下次切换还有多久 |
| 守卫 | `运行中 —— 高峰不消耗任何 token` / `待命` / `已临时放行` / `已关闭` / `⚠ 未生效` |
| 余额 | 当前余额与更新时间 |
| 赠金 / 充值 | 余额构成 |
| 高峰窗口（本机） | 按你所在时区换算后的高峰时段 |
| 当前价目 | 当前时段各模型的输出价 |
| 操作 | 零 token 开关、临时放行、重启服务以启用保护、显示悬浮小卡、查看详情、刷新、官方计价说明 |

### 页面上的悬浮小卡

除了菜单栏标签，页面里还有一张小卡，**默认开启并吸附在会话标题旁「XX模式」徽标右侧约 2 个字符处**（按徽标字号计算，窗口缩放时自动重算）：

- **拖动** → 解除吸附，移到任意位置并记住（位置存在主进程，端口变化或重装都不会丢）
- **双击** → 恢复吸附到「XX模式」右侧
- **点 −** → 折叠成一行
- **悬停** → 完全不透明并展开详情；平时半透明，不干扰阅读

想彻底关掉：菜单「时段与余额 → 在页面上显示悬浮小卡」取消勾选。

## 峰谷计价与「高峰零 token」

按官方 [Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing)：

> 高峰 = **周一至周五 01:00–04:00 与 06:00–10:00（UTC）**，其余时间（含整个周末）为空闲；**空闲价 = 高峰价 5 折**。

北京时间即 **周一至周五 09:00–12:00 与 14:00–18:00**（应用按你的时区自动换算）。

高峰时段应用会**阻止模型调用**，因此不产生任何 token 消耗。这不是"发出请求后取消"，而是在 harness 侧短路了 `llm/stream`，请求根本不会发往 DeepSeek。

需要临时工作时：菜单 →「临时放行至本时段结束」，到点自动恢复拦截。

### 怎么看保护是否真的生效

看「守卫」那一行：

- **运行中 / 待命** → 保护有效（心跳正常）
- **⚠ 未生效** → 说明当前 harness 里没有加载守卫插件（常见于复用了别人启动的服务）。用同菜单里的「重启服务以启用保护」即可

## 设置 API Key

菜单「文件 → 设置…」（`Ctrl+,`）：

- 填入 `sk-` 开头的 Key，点保存 —— 优先用 **Windows DPAPI（safeStorage）加密**存储
- 已保存的 Key **不会被回读显示**，界面只告诉你"是否已配置 / 来源 / 是否加密"
- 也可以直接编辑 `~/.dsh-desktop/config.json`（首次运行会自动创建）
- 解析优先级：环境变量 `DEEPSEEK_API_KEY` → 应用配置（加密或明文）→ `~/.dsh/settings.yaml` 旁的凭据文件

> 余额显示需要 Key；不配置只是看不到余额，不影响对话。

## 窗口、托盘与自启

- **窗口记忆**：位置与大小会被记住，并按当前显示器工作区自动收敛（小屏上不会被任务栏裁掉输入区）
- **托盘**：默认不驻留。勾选「视图 → 关闭时最小化到托盘」后，关闭窗口会隐藏到托盘而不是退出
- **开机自启**：「视图 → 开机自动启动」

## 更新

- **DSH Desktop 自身**：菜单「工具 → 检查 DSH Desktop 更新」→ 查 GitHub Releases → 下载 → 一键安装（会先退出应用，安装完自动重开）
- **dsh（Harness）**：菜单「工具 → 检查 dsh 更新」→ 对比 npm 上的最新版本 → 一键升级 → 提示重启服务

## 日志

- 菜单「工具 → 内置日志查看器」（`Ctrl+Shift+L`）：实时查看、清空、打开所在文件夹
- 日志文件：`~/.dsh-desktop/desktop.log`
